# Free-text passenger wording on four UAE photos

Twelve new typed requests were fixed before running the updated passenger application. The four public photographs and their independent reference areas had been reviewed previously. This study asks whether new wording returns the intended location on familiar scenes. It does not estimate accuracy on new drives. Each trial used a fresh Microsoft Edge session, checked the original photo hash, and submitted the words without clicking a location. No destination was saved. **Two of eight equivalent requests produced an actionable, correctly located first response.** One was a direct point, and one required choosing the point because vehicle size remained uncertain. Five hit the application's 15-second deadline and one returned no location. Three of four contradictory requests withheld a location. The remaining one timed out. None offered a wrong pin. The browser acknowledged all twelve submissions in 72–156 ms. Six then hit the model deadline, including all four conversational two-sentence requests. On each of these three photos the two-sentence wording failed to select an option even with the observations already loaded. On H05 the model labelled the proposed gravel patch blocked, so accepting its location would have required different visual evidence. The three control refusals reported insufficient parking evidence. Their wording does not establish that the app identified the colour difference. ## Follow-up on the same four photographs

After the wording and images were available for diagnosis, a second live run of the identical twelve requests produced **four correct actionable responses out of eight**. Both H04 descriptions returned the right point immediately. The first H02 and H03 descriptions each offered the right location for selection because the vehicles' stated size could not be verified. Both H05 descriptions returned a clarification without a location. The remaining two positive requests and one changed-colour request reached the 15-second deadline. The other three changed-colour requests withheld without presenting a point. No incorrect location or automatic confirmation was observed. The nine completed responses were visible in 0.59–2.67 seconds. [Live outcomes and replayed photo evidence](passenger-language-paraphrases-followup-20261124.json)

The final run used a separate request queue for source-checked photos and broader conversational routing. **Six of eight intended descriptions returned the right location**. Both H04 requests produced a direct point, and all four H02 and H03 requests offered the right location for explicit selection. The two H05 gravel requests asked for clarification without a location. All four changed-colour controls completed and withheld a location. Every response appeared within 0.57–2.20 seconds. The three previous timeouts completed in 0.60–0.62 seconds. All twelve used new sessions on the original photos and the saved decisions were reproduced from the image evidence. The four photographs had already informed the repairs.
