## Latest end-to-end check

The two latest comparisons covered 16 additional UAE drives. Automatic first pins found none of the eight visible storefront and driveway targets. The released app asked for clarification on all eight blocked scenes. After the references were opened, one scripted passenger mark per visible target led to eight checked, confirmed pins inside the intended area. The regular demo includes all sixteen photos. [Street photos, automatic results and assisted results](passenger-frontage-field-test.md)

The latest end-to-end check started with 12 original, unannotated frames from two recordings. The fine-tuned RF-DETR Large and BoT-SORT produced 174 tracked observations. Using those fresh results, the browser API answered a detector-class question on each recording. All four cited image instances opened. The installer also restored all 47 published UAE photos and started the app with 58 prepared scenes and two searchable recordings. [End-to-end results](../experiments/dropoff/project-end-to-end-20261123.json)

Across the 36 fixed footage questions the app returned 25 cited answers and 11 insufficient-evidence responses. We checked the source hashes of all 139 processed image instances sent to Gemini and all 69 cited image instances opened from the app. The result type matched 33 of 35 questions with a specified type. One question asked for human annotations that the detector run did not contain. On the other, the detector found cars and a bus in the first 15 frames and supplied no motorbike track to establish its direction. The separately graded bus-entry question identified the yellow bus and qualified the boundary crossing. Frame-by-frame evidence corrected a previous answer about which way a truck moved. [Questions, responses and checks](../experiments/dropoff/project-end-to-end-20261123.json)

In Edge, real Whisper transcribed both an uploaded WAV and audio recorded through a virtual microphone. After editing the uploaded transcript, the passenger could inspect the suggested location, mark another spot and confirm it. The app rejected the superseded confirmation. On the furniture-store microphone request the app asked for clarification and accepted cancellation. The local fine-tuned 8B also reached confirmation on two EMT recordings using one spoken and one typed request. On the Dubai shop-front control the automatic pin landed inside the predeclared area. The blocked control produced a clarification without a pin. These were scripted demonstrations using known scenes. [Browser, voice and model evidence](../experiments/dropoff/project-end-to-end-20261123.json)

In the earlier test on eight previously unseen UAE photos, the system missed all four clear locations and withheld a pin on all four blocked scenes. Later, after the first photo had been examined, a different spoken description produced a point inside its marked area. That follow-up is a repeat on a known image. ## Earlier release rehearsal

**Footage search.** We replayed all 36 fixed development questions through the regular application. There were 22 answers and 14 insufficient-evidence results. Gemini completed 32 fresh requests. Four searches had no evidence to send and abstained locally. We verified the 136 privacy-processed image instances in the provider receipts. All 64 cited image instances opened and matched the saved file hashes. Retrieved images and intervals respected each question’s frame cutoff. Three targeted checks also matched their predeclared expectations on colour and unmeasurable speed. [Per-question answers, citations, receipts and pre-fix failures](../experiments/dropoff/project-acceptance-20261123.json)

The returned answer-or-abstain status matched 30 of 35 questions with a specified status. Five expected-answer cases abstained, and the bus-entry question had a manual rubric. It identified the visible yellow bus and acknowledged that the supplied evidence could not establish it crossed the image boundary. These counts measure status agreement. Factual correctness requires checking the words against the cited evidence. The original independent development grading and the latest answers are available for that comparison. [Original content grading](../experiments/dropoff/passenger-qa-final36-20261122.json) · [Current responses](../experiments/dropoff/project-acceptance-20261123.json)

**Laptop and fresh installation.** A stress rehearsal with two servers produced host-memory errors. With a warm 8B worker the second request could also run out of GPU memory. The low-memory release processes one demanding operation at a time and frees the local 8B worker between passenger inferences. Consecutive voice and text requests then completed, preserving original photo identity, model provenance and confirmation. Both scripted sessions also rejected a stale proposal ID. A clean-checkout test also found a general “on this frame” query could return empty retrieval. The corrected version opened real evidence for that wording on both recordings. The change left the retrieval scope of all 36 earlier questions identical. [Runtime checks](../experiments/dropoff/project-acceptance-20261123.json)

**Passenger location.** Direct generation on the genuinely reviewed Gulf examples matched the accepted rectangle on **1 of 33** for the locally continued model and **0 of 33** for the pretrained model. It matched the action on 24 of the 44 requests, compared with 19 pretrained. The optional parking specialist and passenger correction run through a separate route. On four additional UAE photos it located one of the two marked clear gaps and withheld a proposal on both blocked scenes. On eight changed phrasings it found two of five eligible gaps and withheld on all three blocked requests. The photo reference polygons came from an AI visual reviewer. Scripted taps recovered three misses in fresh sessions. No actual rider made those confirmations. [Independent 8B comparison](passenger-independent-comparisons.md) · [Parking and assistance results](../experiments/dropoff/passenger-ux-road-validation-20261123.json)

A fresh run of the parking specialist on the Dubai shop-front request returned an automatic point at (2246.4, 1462.1) in original-image pixels, inside the predeclared region. It asked for clarification on the blocked comparison photo. These repeat checks exercise the delivered application on known cases. The Windows test suite passed 2,533 tests, with 35 optional tests skipped. [Current application evidence](../experiments/dropoff/project-acceptance-20261123.json)

## Restore Task 2’s signed package

The evaluation owner can reconstruct the original signed bytes on Windows or Linux. The restore command resolves text line endings against each signed file hash and runs the contributor’s package validator. The destination must be a new, private directory under the ignored runs folder. Install the integration dependencies first.

~~~powershell
git fetch origin Task-2-arjun-part-2
python -m tools.task2_review_package --out runs/private-task2-evaluation
~~~

For training, use the existing importer that selects only the approved non-test records. [Training-only handoff and commands](passenger-human-intake.md)
