## Restore Task 2’s signed package

The evaluation owner can reconstruct the original signed bytes on Windows or Linux. The restore command resolves text line endings against each signed file hash and runs the contributor’s package validator. The destination must be a new, private directory under the ignored runs folder. Install the integration dependencies first.

~~~powershell
git fetch origin Task-2-arjun-part-2
python -m tools.task2_review_package --out runs/private-task2-evaluation
~~~

For training, use the existing importer that selects only the approved non-test records. [Training-only handoff and commands](passenger-human-intake.md)
